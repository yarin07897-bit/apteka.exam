# Аптека API

REST API для управления аптекой: каталог препаратов и учёт продаж.

## Технологии

- Python 3.13
- FastAPI
- SQLAlchemy 2 (async) + PostgreSQL
- Alembic (миграции)
- Docker, Docker Compose

## Возможности

- Просмотр списка препаратов и отдельного препарата по id
- Добавление нового препарата (название, цена, рецептурный, остаток на складе)
- Просмотр списка продаж и отдельной продажи по id
- Регистрация продажи (препарат, количество, дата проставляется автоматически)

## Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/medicines/` | Список препаратов |
| GET | `/medicines/{medicine_id}` | Препарат по id |
| POST | `/medicines/` | Добавить препарат |
| GET | `/sales/` | Список продаж |
| GET | `/sales/{sale_id}` | Продажа по id |
| POST | `/sales/` | Зарегистрировать продажу |

## Как запустить проект

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. Склонируйте репозиторий и перейдите в папку с проектом:
3. Запустите сборку и старт контейнеров:

```bash
   docker compose up --build
```
